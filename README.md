# PICKCAT 自动加后缀
![未命名(2) (1).jpg](https://pic1.imgdb.cn/i/034h2fvGpoCudTVRpkYiYv.jpg)

一个 Chrome / Edge 浏览器扩展，在 [PICKCAT 论坛](https://pickcat.dao3.fun/) 发帖、评论时，自动在行尾追加自定义后缀（默认“喵”）。

## ✨ 功能

- **多种后缀管理**：支持添加任意数量的后缀（如 `喵`、`喵~`、`：）`），通过复选框一键切换。
- **随机模式**：开启后，每次发送会从勾选的后缀中随机抽取一个，告别单调。
- **全局总开关**：点击扩展图标，右上角可一键临时关闭，不想加的时候瞬间静音。
- **发帖/评论全覆盖**：
  - 编辑正文按 Enter 换行时，自动检查上一行并补后缀。
  - 提前换好行，或者只写了一行直接点击“发布/发送”，脚本会瞬间扫描全篇兜底补齐，绝不漏加。
- **智能防误伤**：自动识别并跳过站内的搜索框，不会在搜索时乱加后缀。
- **配置保存在本地**：使用 `chrome.storage.local`，不联网、不上传任何数据。

## 📦 安装

本扩展未上架 Chrome 应用商店，需通过“开发者模式”加载。

1. 前往 [Releases](https://github.com/lszh2012/pickcat-miao/releases) 页面，下载最新的 `pickcat-miao-extension.zip`。
2. 将 zip 解压到任意文件夹（解压后应能看到 `manifest.json` 等文件）。
3. 打开 Chrome / Edge，地址栏输入 `chrome://extensions/` 并回车。
4. 打开右上角的 **开发者模式** 开关。
5. 点击左上角的 **加载已解压的扩展程序**，选择刚才解压出来的文件夹。
6. 打开 [PICKCAT 论坛](https://pickcat.dao3.fun/)，即可生效。

> **注意**：如果以后更新扩展，重复步骤 3-5，选择同一个文件夹覆盖即可。

## 🚀 使用方法

1. 点击浏览器工具栏上的扩展图标，打开设置面板。
2. **总开关**：右上角的开关控制插件的全局启用/禁用。
3. **添加后缀**：在输入框中输入你想要的后缀，点击“添加”。可以添加多个。
4. **后缀切换**：
   - **非随机模式**（默认）：只能勾选一个后缀，点击新的会自动取消旧的。
   - **随机模式**：打开“从勾选的后缀中随机选一个”开关后，可以同时勾选多个后缀，发送时会随机挑选。
5. 正常在 PICKCAT 发帖或评论即可。

## ⚙️ 自定义后缀

点击扩展图标即可随时修改后缀。支持任意文本，包括颜文字、符号、Emoji。

常用配置举例：

- 只加“喵”：`喵`
- 加“喵~”：`喵~`
- 加笑脸：`：）`
- 混合多种：`喵,喵~,：）,uwu`

## ❓ 常见问题

**Q：更新插件后，我之前的设置还在吗？**  
A：在的。脚本内置了数据迁移逻辑，旧版本配置的后缀会自动转换到新版本列表中并默认勾选第一个。

**Q：点击发送没反应，或者没加上后缀？**  
A：请先刷新一下 PICKCAT 论坛的页面。如果仍然无效，请检查弹窗右上角的总开关是否处于开启状态。

**Q：会影响其他网站吗？**  
A：不会。扩展仅在 `https://pickcat.dao3.fun/*` 下运行。

**Q：我的数据会被上传吗？**  
A：不会。所有配置仅保存在你本地浏览器的 `chrome.storage.local` 中。
