# PICKCAT 自动加后缀

一个 Chrome / Edge 浏览器扩展，在 [PICKCAT 论坛](https://pickcat.dao3.fun/) 发帖、评论时，自动在行尾追加自定义后缀（默认“喵”）。

## ✨ 功能

- **发帖编辑**：标题、正文独立检测。正文按 Enter 换行时，自动检查上一行结尾，没有后缀就补上。
- **评论**：自动区分纯文本和 Markdown 格式。
  - 纯文本评论 → 整句结尾补后缀
  - Markdown 评论 → 逐行检测补后缀
- **自定义后缀**：支持设置多个后缀，用英文逗号分隔。插入时使用第一个，检测时匹配任意一个，避免重复添加。
- **配置保存在本地**：使用 `chrome.storage.local`，不联网、不上传任何数据。
- **实时生效**：修改后缀后，已打开的 PICKCAT 页面会自动同步新配置。

## 📦 安装

本扩展未上架 Chrome 应用商店，需通过“开发者模式”加载。

1. 前往 [Releases](https://github.com/你的用户名/pickcat-miao/releases) 页面，下载最新的 `pickcat-miao-extension.zip`。
2. 将 zip 解压到任意文件夹（解压后应能看到 `manifest.json` 等文件）。
3. 打开 Chrome / Edge，地址栏输入 `chrome://extensions/` 并回车。
4. 打开右上角的 **开发者模式** 开关。
5. 点击左上角的 **加载已解压的扩展程序**，选择刚才解压出来的文件夹。
6. 打开 [PICKCAT 论坛](https://pickcat.dao3.fun/)，即可生效。

> **注意**：如果以后更新扩展，重复步骤 3-5，选择同一个文件夹覆盖即可。

## 🚀 使用方法

1. 安装后，点击浏览器工具栏上的扩展图标，弹出设置窗口。
2. 在输入框中填写你想要的后缀，多个用英文逗号 `,` 分隔。
   - 示例：`喵,喵~,：）,uwu`
   - 第一个后缀为默认插入的（例如 `喵`）
   - 检测时，只要行尾是其中任意一个后缀，就不会重复添加。
3. 点击 **保存**，设置立即生效。
4. 正常在 PICKCAT 发帖或评论，脚本会自动为你加上后缀。

### 效果示例

| 你输入的内容 | 实际发送的内容 |
| --- | --- |
| `今天天气不错` | `今天天气不错喵` |
| `今天天气不错喵` | `今天天气不错喵`（不重复加） |
| 正文多行：<br>`第一行`<br>`第二行` | `第一行喵`<br>`第二行喵` |
| Markdown 评论：<br>`- 苹果`<br>`- 香蕉` | `- 苹果喵`<br>`- 香蕉喵` |

## ⚙️ 自定义后缀

点击扩展图标即可随时修改后缀。支持任意文本，包括颜文字、符号、Emoji。

常用配置举例：

- 只加“喵”：`喵`
- 加“喵~”：`喵~`
- 加笑脸：`：）`
- 混合多种：`喵,喵~,：）,uwu`

## ❓ 常见问题

**Q：安装后图标显示成灰色拼图？**  
A：可能是图标路径错误或图片格式不是真正的 PNG。请检查 `manifest.json` 中的 `icon` 路径，并确保图片为 PNG 格式。

**Q：在 PICKCAT 里按 Enter 没有自动加后缀？**  
A：请先刷新 PICKCAT 页面。如果仍然无效，打开开发者工具（F12）查看 Console 是否有 `[加后缀]` 开头的日志，并确认扩展已启用。

**Q：会影响其他网站吗？**  
A：不会。扩展仅在 `https://pickcat.dao3.fun/*` 下运行。

**Q：我的数据会被上传吗？**  
A：不会。所有配置仅保存在你本地浏览器的 `chrome.storage.local` 中。
